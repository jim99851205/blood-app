# PulseCare 血壓管理 App

PulseCare 是一個可直接部署的靜態個人血壓紀錄工具，支援響應式介面、深色/淺色主題、紀錄摘要、資料匯出與本機資料管理。

## 啟動

在 `blood-app` 目錄啟動任一個靜態伺服器：

```bash
python -m http.server 8000
```

然後開啟 <http://localhost:8000>。

## 部署

這個版本不需要建置步驟，可部署到任何靜態網站服務，例如 GitHub Pages、Netlify、Vercel Static 或 Cloudflare Pages。正式部署前請設定 HTTPS、正式網域與自訂錯誤頁。

## 資料與隱私

目前資料使用瀏覽器 `localStorage` 儲存，只存在使用者目前的裝置與瀏覽器，不會同步到伺服器。使用者可透過「匯出資料」下載 JSON 備份；清除瀏覽器資料、無痕模式或更換裝置都可能使資料消失。

若產品要支援跨裝置同步、帳號登入或醫療機構使用，還需要加入後端 API、身份驗證、加密儲存、權限控管、備份策略、隱私政策與相關法規審查，不能直接把目前的本機儲存版本當作醫療資料服務上線。

## 上線前檢查

- 使用 HTTPS 實際網域測試手機與桌面版。
- 確認隱私政策、服務條款與資料保存期限。
- 以實際部署環境檢查匯出檔下載、主題持久化及瀏覽器相容性。
- 進行無障礙鍵盤操作、色彩對比與螢幕閱讀器測試。
- 若加入帳號或雲端同步，先完成安全性與個資法規評估。

## 產品邊界

本工具僅供日常紀錄與整理，不提供診斷、處方或緊急醫療判斷。頁面上的健康提醒不能取代醫師或其他合格醫療專業人員的建議。
